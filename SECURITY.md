# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability, please **do not** open a
public issue.

Instead, report it privately by opening a GitHub Security Advisory in
this repository, or contact the maintainer directly through GitHub.

Please include:

- A clear description of the issue
- Steps to reproduce
- Potential impact
- Suggested remediation (if known)

We will acknowledge receipt as soon as possible and coordinate a
responsible disclosure and fix.
